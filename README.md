# 👵 Elder Care Connect

A MERN Stack based digital platform that helps senior citizens access government welfare schemes, healthcare services, emergency support, and important updates through a simple and accessible platform.

## 🚀 Features

### 🏛️ Government Welfare Schemes
- Information about government schemes available for senior citizens
- Easy access to scheme details and benefits

### 🏥 Healthcare Services
- Government healthcare resources for elderly citizens
- Healthcare information in an easy-to-use format

### 🚨 Emergency Support
- Emergency contact details
- Quick access to important assistance information

### 📢 Government Updates
- Latest updates and announcements related to senior citizens

### 📱 Responsive Design
- User-friendly interface
- Mobile responsive design
- Easy navigation for elderly users

## 🛠️ Tech Stack

### Frontend
- React.js
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MongoDB

## 🎯 Objective

The objective of Elder Care Connect is to bridge the digital gap for senior citizens by providing a single platform to access government welfare schemes, healthcare services, and emergency support.
