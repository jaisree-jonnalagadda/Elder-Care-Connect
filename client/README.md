# Elder Care Connect 👵👴

A MERN Stack based web application designed to help senior citizens easily access government welfare schemes, healthcare services, emergency contacts, and support information.

---

## 🌟 Features

### 🏛️ Government Welfare Schemes
- View available government schemes
- Eligibility information
- Benefits details
- Direct application links

### 🏥 Healthcare Services
- Government healthcare facilities
- Hospital information
- Emergency healthcare support

### 🚨 Emergency Services
- Ambulance contact
- Health helpline
- Elderline support
- Emergency numbers

### 📩 Contact Support
- User enquiry form
- Data stored securely in MongoDB
